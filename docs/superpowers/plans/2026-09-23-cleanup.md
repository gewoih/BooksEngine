**Goal:** удалить из CF-ядра не-книги, дубли произведений, однообразных оценщиков и книги с < 50 оценками —
все правила сразу в `prepare`; затем одним тестом сравнить старое ядро с новым на одних и тех же

## Global Constraints

- Правила (все сразу, в этом порядке после свёртки изданий и сборников): не-книги → слияние уверенных
  дублей → пользователи (sd < 0.2, однообразные, > 3000) → k-core (10, **50**).
- Однообразный оценщик: ≥ 10 оценок и доля самого частого значения (после округления «половина вверх»)
  ≥ 0.9.
- Уверенная тень: тот же ключ «нормализованное название + основной автор» (автор с `role IS NULL`,
  наименьшая `position`), у тени нет номера в серии или он тот же, что у главного, не адаптация и не сборник,
  оценок < 0.1 × главного. Главное — самое оценённое в группе (при равенстве — меньший `work_id`).
- Слияние дублей: оценки пользователя по тени и главному — среднее, взвешенное по `n_editions`, округлено
  до 6 знаков; `n_editions` суммируется. Соответствие «тень → главное» экспортируется в
  `data/clean/work_merges.parquet` (нужно сравнению и позже сопоставлению CSV, п. 11).
- Не-книги и тени остаются в каталоге (`works.parquet`, поиск), уходят только из оценок: `in_cf = false`.
- Настройки моделей — из `models/eval/*_test.json` 3a: ALS `factors=64, regularization=0.1, alpha=1.0`;
  kNN `beta=0.0, k_max=200` + выдача `k=50, normalize=False`; популярность `bayes_log, m=1000`.
  Сохранённые ALS и kNN 3a в `models/<model>/` не перезаписывать; `models/popularity` испорчен тестом
  (`tests/test_evaluate.py`, исправлено 2026-09-23) — популярность для старого ядра обучается заново.
- Обучение нового ядра исключает **всех** пользователей исходного `data/model/split/holdout_users.parquet`
  (val + test), как в 3a. Оценивание — только группа `test`, группы активности — исходные.
- Скрытые книги — общие: только произведения, которые есть в обоих ядрах и не попали во вход
  пользователя ни в одном ядре (после переотображения теней на главное).
- Пороги выдачи в этом плане **не проверяются** (решение пользователя: позже).
- Не запускать `booksengine prepare` до шага сохранения старого ядра (задача 6).
- **`git add` / `git commit` не выполнять**, пока пользователь явно не попросит (`CLAUDE.md`). Шаг
  «Commit» заменён на «проверить `git status`».
- Диск: свободно ~17 ГБ. Копия старого ядра ~0.8 ГБ, модели нового ~0.6 ГБ.
- Документация, комментарии, сообщения — на русском. Команды — `uv run ...`.

## Review Focus

1. У тестового пользователя во входе тень, а в скрытом — главное (или наоборот): после слияния книга не
   должна оказаться одновременно во входе и в скрытом. Тест — задача 5.

   ядер, а не только нового. Тест — задача 5.
5. Сохранённая модель 3a обучена с другими настройками, чем `FIXED`, — сравнение падает с ошибкой, а не

```python
# --- 4a. Не-книги ----------------------------------------------------------------------------------------


def flag_nonbooks(con, patterns: list[str], exceptions: list[int], table: str = "works_valid") -> int:
    """is_nonbook: ноты, раскраски, календари, аудиокурсы — по шаблонам названия (TODO п. 14)."""
    regex = "|".join(f"({p})" for p in patterns)
    # пустой список исключений нельзя подставлять как NOT IN (NULL): это дало бы NULL у всех
    exc = f"AND work_id NOT IN ({', '.join(str(int(w)) for w in exceptions)})" if exceptions else ""
    con.execute(f"ALTER TABLE {table} ADD COLUMN IF NOT EXISTS is_nonbook BOOLEAN")
    con.execute(f"""
        UPDATE {table} SET is_nonbook = regexp_matches(
            lower(coalesce(title, '') || ' | ' || coalesce(best_edition_title, '')), ?) {exc}""", [regex])
    return _one(con, f"SELECT count(*) FROM {table} WHERE is_nonbook")


def drop_nonbooks(con, log: CleaningLog, table: str = "ratings_w") -> None:
    before = _shape(con, table)
    con.execute(f"DELETE FROM {table} WHERE work_id IN (SELECT work_id FROM works_valid WHERE is_nonbook)")
    after = _shape(con, table)
    log.add(Step("nonbooks", "не книги (ноты, раскраски, календари, аудиокурсы): те же читатели, что у книги, "
                 "и попадают в её соседи", before[0], after[0], before[1], after[1], before[2], after[2]))
```

```python
# --- 4b. Дубли произведений -------------------------------------------------------------------------------


def find_duplicates(con, adaptation_patterns: list[str], max_shadow_share: float, table: str = "ratings_w") -> int:
    """dup_map: уверенные «тени» — то же название (без хвостовой скобки и пунктуации, буквы любых алфавитов
    сохраняются) + тот же основной автор + тот же номер в серии, не адаптация и не сборник, оценок меньше
    max_shadow_share от главного (самого оценённого в группе). TODO п. 17."""
    regex = "|".join(f"({p})" for p in adaptation_patterns)
    con.execute(f"""
        CREATE OR REPLACE TEMP TABLE _dup_keys AS
        SELECT w.work_id, p.author_id, c.n,
               trim(regexp_replace(lower(regexp_replace(w.title, '\\s*\\([^)]*\\)\\s*$', '')),
                                   '[^\\p{{L}}\\p{{N}}]+', ' ', 'g')) AS key,
               regexp_extract(coalesce(w.best_edition_title, ''), '#\\s*(\\d+(\\.\\d+)?)\\s*\\)\\s*$', 1) AS series_no
        FROM works_valid w
        JOIN work_primary p USING (work_id)
        JOIN (SELECT work_id, count(*) AS n FROM {table} GROUP BY 1) c USING (work_id)
        WHERE NOT coalesce(w.is_collection, false)
          AND NOT regexp_matches(lower(coalesce(w.title, '') || ' | ' || coalesce(w.best_edition_title, '')), ?)
    """, [regex])
    con.execute("""
        CREATE OR REPLACE TEMP TABLE dup_map AS
        SELECT work_id AS shadow_work_id, main_id AS main_work_id FROM (
            SELECT work_id, n, series_no,
                   first_value(work_id) OVER g AS main_id, first_value(n) OVER g AS main_n,
                   first_value(series_no) OVER g AS main_series
            FROM _dup_keys WHERE key <> ''
            WINDOW g AS (PARTITION BY key, author_id ORDER BY n DESC, work_id))
        -- номер в серии мешает слиянию, только если указан у обоих и различается: у теней его часто нет
        WHERE work_id <> main_id AND (series_no = main_series OR series_no = '' OR main_series = '')
          AND n < ? * main_n
    """, [max_shadow_share])
    con.execute("DROP TABLE _dup_keys")
    return _one(con, "SELECT count(*) FROM dup_map")


def merge_duplicates(con, log: CleaningLog, table: str = "ratings_w") -> None:
    """Оценки тени переносятся на главное; обе у одного человека — среднее, взвешенное по изданиям."""
    before = _shape(con, table)
    both = _one(con, f"""SELECT count(*) FROM {table} s JOIN dup_map d ON d.shadow_work_id = s.work_id
                         JOIN {table} m ON m.user_id = s.user_id AND m.work_id = d.main_work_id""")
    con.execute(f"""
        CREATE OR REPLACE TEMP TABLE _merged AS
        SELECT r.user_id, coalesce(d.main_work_id, r.work_id) AS work_id,
               round(sum(r.rating * r.n_editions) / sum(r.n_editions), 6)::REAL AS rating,
               sum(r.n_editions)::SMALLINT AS n_editions
        FROM {table} r LEFT JOIN dup_map d ON d.shadow_work_id = r.work_id
        GROUP BY 1, 2""")
    con.execute(f"DROP TABLE {table}")
    con.execute(f"ALTER TABLE _merged RENAME TO {table}")
```

```python
        works_all = w if works_all is None else works_all & w
        inputs[name] = _remapped_input(inp, d, w)
    used = pd.concat([x[["user_id", "work_id"]] for x in inputs.values()]).drop_duplicates()
    h = hid[hid.user_id.isin(users) & hid.work_id.isin(works_all)]
    h = h.merge(used, how="left", indicator=True).query("_merge == 'left_only'").drop(columns="_merge")
    keep = set(h.user_id)
    for x in inputs.values():
        keep &= set(x.user_id)
    h = h[h.user_id.isin(keep)].sort_values(["user_id", "work_id"], ignore_index=True)
    hu = test_users[test_users.user_id.isin(keep)].sort_values("user_id", ignore_index=True)
    for name, x in inputs.items():
        o = out_dir / name
        o.mkdir(parents=True, exist_ok=True)
        x[x.user_id.isin(keep)].sort_values(["user_id", "work_id"], ignore_index=True).to_parquet(
            o / "test_input.parquet", index=False)
        h.to_parquet(o / "test_hidden.parquet", index=False)
        hu.to_parquet(o / "holdout_users.parquet", index=False)
    meta = {"users": len(keep), "users_dropped": len(test_users) - len(keep), "hidden": len(h),
            "hidden_dropped": int(hid.user_id.isin(set(test_users.user_id)).sum()) - len(h)}
    (out_dir / "common.json").write_text(json.dumps(meta, indent=1))
    return meta


def _profile_input(profile_path: Path, work_ids: np.ndarray) -> sp.csr_matrix:
    """Оценённые книги профиля (1–10 → 1–5); dnf и книги вне ядра пропускаются."""
    p = pd.read_csv(profile_path)
    p = p[(p.status == "read") & p.rating.notna() & p.goodreads_work_id.isin(work_ids)].sort_values(
        "goodreads_work_id")
    cols = columns(work_ids, p.goodreads_work_id.to_numpy())
    vals = p.rating.to_numpy(dtype=np.float32) / 2
    return sp.csr_matrix((vals, (np.zeros(len(cols), dtype=int), cols)), shape=(1, len(work_ids)))


def _model(m: str, path: Path, train):
    """Сохранённая модель с настройками FIXED — или новая, обученная и сохранённая. Чужие настройки — ошибка:
    иначе сравнение молча меряет не ту модель, а перезапись испортила бы модели 3a."""
    cls = MODELS[m][0]
    fit_params, score_params = FIXED[m]
    if (path / "params.json").exists():
        saved = read_params(path)
        if any(saved.get(k) != v for k, v in fit_params.items()):
            raise ValueError(f"{path}: настройки {saved} не совпадают с {fit_params}")
        model, fit_s = cls.load(path), None
    else:
        model = cls(**fit_params)
        t0 = time.perf_counter()
        model.fit(train)
        fit_s = round(time.perf_counter() - t0, 1)
        model.configure(**score_params)
        model.save(path)
    model.configure(**score_params)
    return model, fit_s


def run_core(name: str, *, ratings_path: Path, works_path: Path, common_dir: Path, holdout_path: Path,
             profile_path: Path, model_dir: Path, eval_dir: Path, models=("popularity", "als", "knn")) -> dict:
    train = load_train(ratings_path, holdout_path)
    hold = load_holdout(common_dir, "test", train.work_ids)
    titles = duckdb.execute("SELECT work_id, title FROM read_parquet(?)", [str(works_path)]).df() \
        .set_index("work_id")["title"]
    prof = _profile_input(profile_path, train.work_ids)
    out = {"core": name, "n_users": int(len(hold.user_ids)), "models": {}}
    eval_dir.mkdir(parents=True, exist_ok=True)
    for m in models:
        model, fit_s = _model(m, model_dir / m, train)
        per_user, cov = run_eval(model, hold)
        top = metrics.top_k(model.score(prof), prof, min(metrics.K, prof.shape[1]))[0]
        out["models"][m] = {"fit_seconds": fit_s, "summary": metrics.summarize(per_user), "coverage": cov,
                            "profile": [str(titles.get(train.work_ids[c], c)) for c in top if c >= 0]}
        print(f"{name} {m}: NDCG@20 = {out['models'][m]['summary']['all']['ndcg20']['mean']:.4f}", flush=True)
        (eval_dir / f"{name}.json").write_text(json.dumps(out, ensure_ascii=False, indent=1))
    return out
```
